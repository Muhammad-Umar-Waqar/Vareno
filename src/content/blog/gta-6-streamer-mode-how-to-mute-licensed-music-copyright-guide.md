## 2. Step-by-Step: How to Enable Streamer Mode

Rockstar Games designed an intuitive, multi-tier audio filtering system in the settings menu:

```
┌─────────────────────────────────────────────────────────────┐
│                 HOW TO TURN ON STREAMER MODE                │
├─────────────────────────────────────────────────────────────┤
│ 1. Press Pause (Options / Menu) during gameplay.            │
│ 2. Scroll to the 'Settings' tab.                            │
│ 3. Select 'Audio'.                                          │
│ 4. Scroll down to the 'Broadcasting & Streaming' section.   │
│ 5. Toggle 'Streamer Mode' to 'ON'.                          │
│ 6. Select 'Filter Mode' -> 'Mute Licensed Music Only'.       │
└─────────────────────────────────────────────────────────────┘
```

### Audio Filter Settings Explained:
* **Option A: Streamer Mode (Full Safe Mode):** Completely silences all commercial radio stations and ambient club speakers, replacing them with original, copyright-cleared instrumental music scored by Rockstar.
* **Option B: Mute Licensed Music Only (Recommended):** Mutes commercial music tracks while keeping radio DJ dialogue, satirical news updates, satirical commercials, and emergency weather alerts completely audible.
* **Option C: Disable Music in Vehicles:** Automatically turns car stereos off upon entering any vehicle, leaving only vehicle engine rumblings and road sounds.
